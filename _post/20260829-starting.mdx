I've wanted to start a blog for a while but like all project ideas they get dumped somewhere in the back of my head.
Recently though as I started to move house my interest in making things has picked back up.
So I thought this would be a great time to revive this idea and here is what I hope to achieve with this blog:

- Encourage myself to start and finish a project before moving onto the next by writing down the journey as I go.
- Improve my technical writing skills, particularly around explaining concepts and methodologies.
- An excuse to learn a little bit of NextJS for something simple.

So lets revisit this back in a years time and see how I did!
